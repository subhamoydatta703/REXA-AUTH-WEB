# Backend

Simple backend server built with Express, TypeScript, Prisma, and Bun for REXA.

## Prerequisites

- [Bun](https://bun.com) installed on your machine.

## Getting Started

To install dependencies:

```bash
bun install
```

To run the application:

```bash
bun run index.ts
```

This project uses Express, Prisma, and PostgreSQL.
